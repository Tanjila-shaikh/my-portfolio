# My Portfolio

A beautiful, modern portfolio website showcasing my skills, projects, and experience as a developer.

## 🚀 Features

- **Responsive Design** - Works perfectly on all devices
- **Dark/Light Mode** - Toggle between themes
- **Animated UI** - Smooth animations and transitions
- **Contact Form** - Functional contact form with email integration
- **Project Showcase** - Display your best work
- **Skills Section** - Highlight your technical expertise

## 🛠️ Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Icons:** Lucide React
- **UI Components:** Radix UI
- **Backend:** Node.js, Express, Nodemailer
- **Deployment:** Ready for GitHub Pages / Vercel / Netlify

## 🏃‍♂️ Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Tanjila-shaikh/my-portfolio.git
cd my-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Set up environment variables:
Create a `.env` file in the root directory:
```env
EMAIL_USER=your-gmail@gmail.com
EMAIL_PASS=your-gmail-app-password
```

4. Start the development server:
```bash
npm run dev
```

5. Start the backend server (for contact form):
```bash
npm run server
```

6. Open [http://localhost:5173](http://localhost:5173) in your browser

## 🎨 Customization

### Personal Information
Update the following files with your information:
- `src/components/HeroSection.jsx` - Name, title, description
- `src/components/AboutSection.jsx` - About content
- `src/components/SkillsSection.jsx` - Your skills
- `src/components/ProjectsSection.jsx` - Your projects
- `src/components/ContactSection.jsx` - Contact information

### Styling
- Colors and themes can be customized in `src/index.css`
- Tailwind configuration in `tailwind.config.js`
